## Python (Bleak)

```python
import asyncio
from bleak import BleakClient

ADDRESS = "XX:XX:XX:XX:XX:XX"  # your watch
TX_UUID = "00000af6-0000-1000-8000-00805f9b34fb"  # 16-bit 0x0AF6

PAYLOAD = bytes([0x03, 0xE3, 0x10, 0x02])

async def main():
    async with BleakClient(ADDRESS) as client:
        await client.write_gatt_char(TX_UUID, PAYLOAD, response=True)
        print("Sent:", PAYLOAD.hex())

asyncio.run(main())
```
